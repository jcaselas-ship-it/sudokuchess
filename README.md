# Sudoku de ajedrez

Sudoku con piezas de ajedrez en 4×4, 6×6 y 9×9, para jugar en el navegador o instalar como app (PWA) en móvil, tablet u ordenador.

- Tres dificultades graduadas por técnica de resolución.
- Modos Libre, Desafío (3 fallos y 3 pistas) y Contrarreloj, con récords.
- Notas, deshacer y rehacer, guardado automático y pistas que explican el razonamiento.
- Funciona sin conexión una vez instalado.

**Jugar:** https://jcaselas-ship-it.github.io/sudokuchess/ (activa GitHub Pages en Settings → Pages → rama `main`).
